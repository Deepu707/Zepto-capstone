# Zepto Capstone — AI & ML Platform

A single end-to-end AI/ML capstone for the Certificate Program in
Artificial Intelligence and Machine Learning. Three internally-linked
modules live side by side in one repository:

| Module | Folder | Marks | Summary |
|---|---|---|---|
| 1. Data Pipeline | `/data_pipeline` | 25 | Scrape, clean, convert, and store book data in a normalized SQLite DB |
| 2. Analytics Pipeline | `/analytics` | 50 | Profile, visualize, and model the Titanic dataset end to end |
| 3. Support Assistant | `/support_assistant` | 25 | Grounded RAG over Zepto's own policy documents |
